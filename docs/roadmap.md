# Research roadmap and release boundaries

**PROPOSED RESEARCH · NOT COMPLETED MILESTONES**

The current repository provides a source catalog, conceptual example, and documentation website. It does not execute the methods below. The proposed 36-month schedule has no funded start date in this release.

| Proposed phase | Research and infrastructure work | Intended reviewable outputs |
|:--|:--|:--|
| Year 1 · Establish | Reconcile source files, identifiers, rights and annotation definitions; assess evidence coverage; design process/event schemas and baseline transformations | Rights-reviewed manifests, baseline enhanced data, expert-audit protocol, frozen evaluation partitions |
| Year 2 · Enhance and evaluate | Investigate bounded agentic enhancement, temporal and semantic harmonization, process-aware checks, and scalable graph views | Versioned enhancements, source-bearing graphs, comparative fidelity and cost reports |
| Year 3 · Independently assess and preserve | Evaluate evidence-grounded inquiries, held-out confirmation, external reuse, documentation and stewardship | Scientific benchmarks, reproducibility reports, community releases, archival and maintenance arrangements |

## Scientific questions, not completed capabilities

**Reconstruction:** Which events and dependencies can be supported by the actual observations, and which remain unresolved?

**Cross-campaign reuse:** Which representations and documented anomaly signatures remain useful between the two campaigns on the same testbed? Independent factory data would be required for cross-factory claims.

**Evidence sufficiency:** Which scientific questions are answerable using the available records? A process graph, model consensus, or temporal ordering does not by itself establish a causal effect.

## Resource-centered evaluation

Proposed evaluation separates representation, coordination, and verification at matched evidence and compute budgets. Dataset coverage, source attribution, uncertainty, review effort, reproducibility, and independent usability matter alongside prediction accuracy. Simpler methods remain valid outcomes when agent coordination adds no reproducible benefit.

The proposal's planned expert review and three external reuse pilots are future activities. This repository does not certify annotation sample adequacy, reviewer availability, pilot participation, or infrastructure commitments.

## Before a future enhanced-data release

A release would need file-level source and rights review, traceable derivations, explicit evidence status, validated schemas, documented limitations, leakage-resistant partitions, and authorized approval. Original observations and actual process deviations must not be overwritten to enforce a nominal procedure. These are proposed policies; the current documentation checks do not implement them.

## What is deliberately absent

No trained model checkpoints, fabricated event tables, raw manufacturing files, automated scientific verifier, new collection campaign, factory controller, completed benchmark scores, or claims of enhanced-data validation are included. Real preliminary work may be added later with accurate methods, evidence, provenance, and limitations; it should never be concealed or inflated.
