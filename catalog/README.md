# Catalog files

[Return to dataset catalog](../README.md#dataset-catalog)

`datasets.json` holds four source descriptions grouped by two campaigns. `upstream-links.csv` lists all eleven source URLs. `link-checks.json` records the limited verification scope. The four Markdown cards are written for human readers and cite their primary publication locations.

All counts are publication-reported. `download_verified`, `raw_file_license_verified`, `file_inventory_audited`, and `source_version_pinned` intentionally remain false. A future audit must record its actual evidence before changing these values.

This file format is for catalog maintenance only. It is not MANIFOLD's proposed scientific PEG validation schema.
