# Security and sensitive information

[Return to MANIFOLD](README.md)

This is a static documentation and illustrative-viewer repository. It has no factory connection, account system, data-upload endpoint, or remote AI execution service. That limited scope does not constitute a security guarantee.

Do not post tokens, credentials, personal data, worker imagery, or restricted industrial information in public issues. For a vulnerability or sensitive disclosure, use GitHub's private vulnerability reporting control **if the owner has enabled it**. Otherwise contact the repository owner through a verified institutional channel shown on their profile; no unverified email address is supplied here. Do not include sensitive details in a public request for a contact method.

Maintainers should enable private vulnerability reporting before inviting reports, review dependencies and workflow changes, and inspect every publication artifact. No response-time service level or dedicated security operation is claimed.

The supplied workflows build documentation and run local consistency tests. They do not evaluate prompt injection against an operational MANIFOLD agent or validate manufacturing evidence. Such research remains proposed.
