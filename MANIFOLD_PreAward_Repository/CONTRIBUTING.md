# Contributing to the planning catalog

[Return to MANIFOLD](README.md)

At this stage, useful contributions are **source corrections, broken-link reports, documentation improvements, and specific future reuse questions**. Contributions are proposals, not automatically accepted dataset evidence.

## Submit a correction

Use the repository's Issues tab and select **Catalog correction**. Give the asset ID, current wording, suggested correction, primary source URL and page/section, and the scope of your check. Distinguish opening a landing page from downloading or auditing files. A maintainer reviews the evidence before merging a change.

## Describe a future reuse need

Use **Research reuse interest** to describe the scientific question, source asset, required enhancement, evidence requirements, and barriers to independent use. This does not enroll anyone in a funded pilot or establish a partnership.

## Pull requests

Keep edits focused. Run `python tools/check_repository.py`, the unit tests, and the website build. Update the source ledger when factual metadata changes. Repository checks cover documentation and structure only; do not describe them as scientific validation.

Do not upload manufacturing archives, personal information, worker images, secrets, restricted records, proposal PDFs, budgets, unsupported benchmark scores, or material you lack permission to redistribute. Discuss sensitive matters privately according to [SECURITY.md](SECURITY.md).
